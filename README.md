# Project 1: Todo Basic Performance Testing

## Website Scenario
- Newly launched application. Users are going around application trying out all the features, leading to an even distribution amongst user stories.

## User Distribution
- 25% - As a new user I can register an account to start tracking my todo tasks
- 25% - As a new user I can log in and out to securely access my todo items 
- 25% - As a user I can create and edit todo items to keep track of my work
- 25% - As a user I can create and edit subtask items to better organize my primary tasks
